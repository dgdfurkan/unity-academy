# Unity Lesson

An interactive platform for learning Unity and C#.

Lessons combine explanation, a live C# editor, 3D scenes for spatial concepts, and
exercises that check your work as you go. Progress, scoring, and spaced repetition are
tracked per student.

The frontend is static and ships to GitHub Pages. Data and authentication run on a
separate API server.

See `docs/BRIEF.md` for scope and roadmap.
