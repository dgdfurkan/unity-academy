# Unity Academy

An interactive platform for learning Unity and C#.

Lessons pair explanation with practice: you read the idea, then write the C# in the
browser and have it checked. Spatial topics such as `Rigidbody`, `Collider`, and
`Raycast` are taught with live 3D scenes instead of paragraphs. Progress, scoring, and
spaced repetition are tracked per student.

Turkish by default, English at `/en`. Unity and C# API names are never translated.

The frontend is static and ships to GitHub Pages. Data and authentication run on Firebase.

See `docs/BRIEF.md` for scope and `docs/DESIGN.md` for interface decisions.
